# FreeLeader 技术与部署说明

## 产品形态

- 电脑端优先的组长工作台。
- 手机端优先的成员专属任务页。
- 组长通过 ChatGPT 登录；成员通过随机、可过期、可撤销的任务链接访问。

## 前端

- Vinext / React 响应式页面。
- 主要入口：项目创建、任务方案、组长工作台、成员提交、质量预审、整合审阅。
- 手机端将管理信息收敛为“任务—标准—提交—反馈”主路径。

## 后端与 API

- `/api/projects`：创建和读取组长自己的项目。
- `/api/member/:token`：验证成员任务链接。
- `/api/member/:token/submit`：保存正文/附件、创建新版本并触发预审。
- `/api/ai/review`：登录后的组长可直接调用质量预审。
- 所有写操作都在服务端验证身份或链接权限，前端显示状态不作为授权依据。

## 数据库

Cloudflare D1 保存：

- 用户与项目。
- 成员与任务链接哈希。
- 任务卡与验收标准。
- 提交、版本与预审结果。
- 冲突、组长决策和整合文档。
- 审计日志。

索引围绕真实查询建立：组长项目列表、项目任务状态、成员提交、文件指纹重复检查和项目审计时间线。

## 文件处理

- Cloudflare R2 保存 Word、PDF、Markdown 和纯文本附件。
- D1 只保存文件元数据、对象键、大小、类型和 SHA-256。
- 单文件限制 10 MB。
- 相同项目内使用 SHA-256 检查完整重复文件。
- 当前版本可安全上传和记录复杂 Word/PDF；对复杂表格、扫描 PDF 和 OCR 的深度解析属于下一阶段。

## AI 调用

- 默认先运行确定性规则，确保没有模型密钥时产品仍能验证流程。
- 配置 `OPENAI_API_KEY` 后，后端通过 OpenAI Responses API 调用模型。
- 可用 `OPENAI_MODEL` 指定模型；未设置时使用代码中的默认模型。
- 模型输出使用 JSON Schema 结构化结果。
- 发送到模型的内容不在浏览器端处理，密钥不会暴露给成员。
- 模型失败时自动退回确定性规则，不丢失成员提交。

## 权限矩阵

| 行为 | 组长 | 当前任务成员 | 其他成员 |
|---|---:|---:|---:|
| 查看项目全局进度 | 是 | 否 | 否 |
| 修改分工与标准 | 是 | 否 | 否 |
| 查看自己的任务 | 是 | 是 | 否 |
| 查看自己的提交与反馈 | 是 | 是 | 否 |
| 查看其他成员完整原文 | 是 | 否 | 否 |
| 覆盖 AI 判断 | 是 | 否 | 否 |
| 处理 P0/P1 冲突 | 是 | 否 | 否 |
| 导出整合文档 | 是 | 否 | 否 |

## 上线前仍需完成

1. 在托管环境中设置 `OPENAI_API_KEY`，不要写入仓库。
2. 明确隐私政策、数据保存时长和一键删除项目机制。
3. 给真实成员链接设置合理过期时间，并提供撤销入口。
4. 增加文件病毒扫描、速率限制和更严格的内容类型验证。
5. 根据 2–3 个真实小组的测试结果，再决定是否开发微信小程序通知层。
